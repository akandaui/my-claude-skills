## Skills

### `white-space-design`
Applies white space and minimalism principles to UI/UX design — based on the UXPin **"Zen of White Space in Web UI Design"** framework.

**Triggers when you ask about:**
- Spacing feeling off or too cluttered
- Breathing room in layouts
- Minimalism decisions
- Visual hierarchy through space
- Padding/margin guidance
- Reviewing a UI for spacing quality

**What it does:**
- Reviews designs using the macro/micro and passive/active white space framework
- Gives spacing recommendations grounded in design theory
- Advises on when minimalism is and isn't appropriate
- Provides practical CSS starting values
- Includes a from-scratch design workflow and audit checklist

**Source:** UXPin — *Zen of White Space in Web UI Design* (Cao, Rocheleau, Zieba, Ellis)

## How to Install

1. Download the `.skill` file from the releases
2. In Claude, go to **Settings → Skills**
3. Click **Install Skill** and select the file

Or clone this repo and point Claude to the `white-space-design/` folder directly.
